# C-program-Tic-Tac-Toe-Game-
This project is a C program Tic Tac Toe game.
Players take turns selecting positions on a grid. The program updates the board, evaluating win conditions after each turn and checking for vaild moves. This continues until all positions are filled (draw) or a player wins.
Array tracks current stae of the board.
Implements predefined winning combinations.
Conditional logic alternates player turns.
Moves are tracked to determine draw conditions.
